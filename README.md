# Tier3 Media homepage reference

A static, premium editorial redesign of https://tier3media.com/.

## Delivery

The website lives in `wordpress/reference`. Plain HTML, CSS, and JavaScript; no build step or WordPress runtime. Website assets are local. Qualification and other business links lead to the existing live services. No forms submit locally.

## Workflow

The foundation commit is on `main`. All subsequent work is on `redesign`, with one commit per goal:

1. Repository foundation.
2. Verified content, original assets, and approved design direction.
3. Complete responsive homepage.
4. Motion and accessibility.
5. Verification, fixes, and handoff documentation.

No remote or deployment is configured.
